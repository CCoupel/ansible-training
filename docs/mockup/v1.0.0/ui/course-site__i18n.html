What is an Inventory?

  • Definition: The list of managed nodes (or hosts) that Ansible configures.
  • Formats: Various formats, with INI and YAML.
  • Default Location: The default inventory file is located at /etc/ansible/hosts.
  • Groups: Hosts can be organized into groups to simplify management and task execution.
  • Dynamic Inventory: Plugins to generate inventories from external sources
